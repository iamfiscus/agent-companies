Select one major feature and run the agent-native checklist:

1. **Capability map** — Can agents achieve all user outcomes through tools?
2. **Granularity check** — Are tools atomic or bundled?
3. **Composability check** — Can new prompts create new features without code?
4. **Emergent capability test** — Try an unexpected request, see if the agent composes a solution

Document findings. Create remediation tasks for any parity gaps.
